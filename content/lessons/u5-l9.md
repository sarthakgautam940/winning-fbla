Neural networks sit behind image recognition, speech assistants, and large language models, and the test expects you to know how one works from the inside: what a single neuron computes, what each activation function does, how many parameters a network has, and the order of the steps that train it. The calculations are short. The traps are in the vocabulary, so learn each term exactly.

## One neuron: weighted sum, bias, activation

An **artificial neuron** is a small computing unit loosely inspired by a brain cell. It receives several numbers as inputs, combines them into one number, and passes that number through a function that decides its output. Three ingredients do the work:

- A **weight** for each input says how much that input counts. A large positive weight makes the input push the output up, a negative weight pushes it down, and a weight near 0 means the input barely matters.
- A **bias** is one extra number added to the total. It shifts the neuron's threshold: with a large bias the neuron activates easily, and with a negative bias the inputs must push hard. It also lets the neuron output something other than 0 when every input is 0. It plays the same role as the intercept of a line.
- An **activation function** turns the total into the neuron's output.

In symbols, a neuron with two inputs computes a **weighted sum** z, then applies the activation f:

$$
z = w_1 x_1 + w_2 x_2 + b, \qquad \text{output} = f(z)
$$

With more inputs, the sum simply gets more terms. Training never changes the inputs; it adjusts the weights and the bias.

::::example[Compute a neuron's output]
A neuron has inputs $$x_1 = 4$$ and $$x_2 = 1$$, weights $$w_1 = 0.5$$ and $$w_2 = -1$$, and bias $$b = 0.5$$. It uses the ReLU (rectified linear unit) activation, which outputs z when z is positive and 0 otherwise. Find its output.

:::step
Multiply each input by its weight: 4 × 0.5 = 2, and 1 × (-1) = -1.
:::

:::step
Add the products and the bias: z = 2 - 1 + 0.5 = 1.5.
:::

:::step
Apply ReLU. Because 1.5 is positive, ReLU passes it through unchanged.
:::

:::answer
The output is 1.5. With a bias of -2 instead, z would be 2 - 1 - 2 = -1, and ReLU would output 0: the same inputs, a different bias, and the neuron stays silent.
:::
::::

One of the earliest learning neurons was the **perceptron**, introduced by Frank Rosenblatt in a 1958 paper after a first description in a 1957 report. It used a **step activation**, which outputs 1 when z is at least 0 and 0 otherwise, and it adjusted its weights from labeled examples. Today's neural networks are its descendants.

### Logic with a single neuron

With inputs of 0 and 1, a step neuron can act as a logic gate. Give both inputs a weight of 1 and compare two biases:

| Inputs (x1, x2) | z with bias -1.5 | Output | z with bias -0.5 | Output |
|---|---|---|---|---|
| (0, 0) | -1.5 | 0 | -0.5 | 0 |
| (0, 1) | -0.5 | 0 | 0.5 | 1 |
| (1, 0) | -0.5 | 0 | 0.5 | 1 |
| (1, 1) | 0.5 | 1 | 1.5 | 1 |

With bias -1.5, the neuron fires only when both inputs are 1, so it computes **AND**. With bias -0.5, one input is enough, so it computes **OR**. The weights never changed; the bias alone moved the threshold.

## Layers and networks

A single neuron has a hard limit. It outputs 1 on one side of the boundary where $$w_1 x_1 + w_2 x_2 + b = 0$$, and that boundary is a straight line. So one neuron can only separate its inputs with a single straight line, a **linear decision boundary**.

Now consider **XOR** (exclusive or), which outputs 1 when exactly one input is 1. Picture the four input pairs as the corners of a square. XOR's 1s, at (0, 1) and (1, 0), sit on one diagonal, and its 0s, at (0, 0) and (1, 1), sit on the other. No single straight line puts both 1s on one side and both 0s on the other, so no single perceptron can compute XOR.

The fix is to connect neurons in layers. A **neural network** is a model made of layers of connected artificial neurons, in which the outputs of one layer become the inputs of the next, and whose weights and biases are learned from data.

- The **input layer** holds the features, one node per feature. It does no computation; it passes the values along.
- **Hidden layers** sit between the input and output layers. Their values are neither data you supply nor predictions you read, which is why they are called hidden. Each hidden layer builds new features out of the previous layer's outputs.
- The **output layer** produces the prediction: one neuron for a number or for a yes-or-no probability, or one neuron per class for a multiclass problem.

In a **fully connected** (or dense) layer, every neuron receives every output of the layer before it. A network in which information flows only forward, from input to output, with no loops, is a **feedforward network**. A basic feedforward network of fully connected layers is often called a **multilayer perceptron** (MLP).

```figure
type: network
layers: [3, 4, 2]
labels: [Input layer, Hidden layer, Output layer]
caption: A fully connected network with 3 inputs, one hidden layer of 4 neurons, and 2 outputs. Every line is a weight, and every hidden and output neuron also has its own bias.
```

A hidden layer solves XOR. One hidden neuron computes OR, another computes NAND (not both), and the output neuron computes the AND of those two results. The output is 1 exactly when one input is 1. Layers let a network combine simple straight boundaries into complex ones.

:::tip
**Test tip.** "Cannot learn XOR" or "only linearly separable problems" points to a single perceptron. The fix is always the same: add a hidden layer.
:::

## Activation functions

Every hidden layer needs a **nonlinear** activation function. Without one, each layer computes a weighted sum, and a weighted sum of weighted sums is still a weighted sum: a network of any depth would collapse into a single linear model, no more powerful than linear regression. Nonlinear activations are what let a network bend its boundaries around complex patterns.

The common choices and their output ranges are frequent test items:

| Activation | Rule | Output range | Typical use |
|---|---|---|---|
| Step | 1 if z is at least 0, else 0 | 0 or 1 | The original perceptron |
| Sigmoid | $$\frac{1}{1 + e^{-z}}$$ | 0 to 1 | Output for yes-or-no probabilities |
| tanh | S-shaped, centered on 0 | -1 to 1 | Hidden layers, especially in recurrent networks |
| ReLU | max(0, z) | 0 to infinity | The default for hidden layers |
| Softmax | Turns a list of scores into probabilities | Each 0 to 1, summing to 1 | Output for multiclass problems |

A few values are worth knowing on sight: the sigmoid of 0 is 0.5, tanh of 0 is 0, ReLU of -3 is 0, and ReLU of 2.5 is 2.5. ReLU is the default for hidden layers because it is fast to compute and keeps gradients healthy, as a later section shows. A variant, **leaky ReLU**, gives negative inputs a small slope instead of a flat 0, so a neuron cannot get stuck outputting 0 forever.

```figure

xLabel: Weighted sum z
yLabel: ReLU output
caption: ReLU outputs 0 for every negative input and passes positive inputs through unchanged. The bend at 0 is the nonlinearity.
```

### Softmax for multiclass outputs

**Softmax** takes the output layer's raw scores, one per class, and turns them into probabilities. It raises e to the power of each score and divides each result by their total, so every output is between 0 and 1 and the outputs sum to 1. For scores of 2, 1, and 0, the exponentials are about 7.39, 2.72, and 1, which total 11.11. The probabilities are about 0.67, 0.24, and 0.09, and the network predicts the first class. Notice that the last class still gets 0.09 even though its score is 0, because e to the 0 is 1, not 0.

## Counting parameters [Competitive]

The **parameters** of a network are its weights and biases, the numbers training adjusts (lesson 5.1). Counting them is a standard question, and it takes one rule. A fully connected layer that receives n inputs and has m neurons has:

- n × m weights, one for every connection, and
- m biases, one per neuron.

Add the counts for every layer. The input layer has no weights or biases of its own, because its values come straight from the data.

::::example[Count the parameters]
A network has 4 inputs, a hidden layer of 5 neurons, and 3 output neurons, all fully connected. How many parameters does it have?

:::step
Input to hidden: 4 × 5 = 20 weights, plus 5 biases, for 25.
:::

:::step
Hidden to output: 5 × 3 = 15 weights, plus 3 biases, for 18.
:::

:::answer
The network has 25 + 18 = 43 parameters.
:::
::::

Counts grow fast. One layer that receives 1,000 inputs and has 100 neurons already holds 1,000 × 100 + 100 = 100,100 parameters, and AlexNet, the 2012 image network you will meet in lesson 5.10, had about 60 million. The number of layers and the number of neurons in each are hyperparameters, chosen before training; the weights and biases are the parameters that training learns.

:::trap
**Common trap.** The usual wrong answers forget the biases or multiply all the layer sizes together. Count each layer separately: inputs × neurons, plus one bias per neuron.
:::

::check{id="neurons-05"}

## Forward pass, loss, backpropagation, update

Training repeats one loop thousands or millions of times. Before the first pass, the weights are set to small random numbers. If they all started equal, every neuron in a layer would compute the same output and receive the same correction, and the neurons would never become different from one another.

1. **Forward pass.** Feed a batch of training examples in at the input layer. Each layer computes its outputs and passes them on until the output layer produces predictions.
2. **Compute the loss.** Compare the predictions with the true labels using a loss function: mean squared error for numbers, cross-entropy for classes (lesson 5.7).
3. **Backpropagation.** Work backward from the loss, layer by layer, to find the gradient for every weight and bias: how much the loss would change if that parameter changed slightly.
4. **Update.** Gradient descent moves every parameter a small step against its gradient, scaled by the learning rate.

```figure
type: flow
steps: [Forward pass, Compute loss, Backpropagation, Update weights]
cycle: true
caption: One training step. The loop repeats for every batch, epoch after epoch, until the loss stops improving.
```

**Backpropagation**, short for backward propagation of errors, uses the chain rule from calculus so that each layer's gradient reuses the results already computed for the layer after it, which makes the whole calculation efficient. It was popularized in a 1986 paper by David Rumelhart, Geoffrey Hinton, and Ronald Williams, which showed that it lets hidden layers learn useful features of their own; its mathematics goes back to Seppo Linnainmaa (1970) and Paul Werbos (1974).

:::trap
**Common trap.** Backpropagation computes the gradients; it does not change any weight by itself. The update step, gradient descent, uses those gradients. And what flows backward is error information, not the data.
:::

The learning rate matters exactly as it did in lesson 5.7: too small and training crawls, too large and the loss bounces or climbs. Once training ends, using the network to make predictions, called **inference**, is just the forward pass with the weights held fixed.

::check{id="nn-training-01"}

## Vanishing gradients [Champion]

Backpropagation multiplies slopes together as it moves backward through the layers, and that creates a problem for S-shaped activations. The sigmoid's slope is at most 0.25, at z = 0, and it is nearly 0 wherever the curve flattens out, which is called **saturation**. Multiply ten slopes of 0.25 together and you get about 0.000001. The gradients that reach the early layers of a deep sigmoid network can shrink toward zero, so those layers barely learn. This is the **vanishing gradient** problem.

ReLU's slope is exactly 1 for every positive input, so gradients pass through active ReLU neurons without shrinking. That is a major reason ReLU replaced the sigmoid in hidden layers and helped make deep networks trainable. The opposite problem, **exploding gradients**, happens when the multiplied factors are large and the gradients grow out of control; it is common in recurrent networks (lesson 5.10).

::check{id="activations-05"}

## Epochs, batches, and iterations [Competitive]

Three words describe how much data training has seen, and test questions mix them up on purpose:

- An **epoch** is one full pass through the entire training set.
- The **batch size** is the number of examples used for one update.
- An **iteration**, or step, is one update of the weights, made from one batch.

So one epoch contains the number of training examples divided by the batch size, rounded up when it does not divide evenly, because the leftover examples form one last, smaller batch:

$$
\text{iterations per epoch} = \left\lceil \frac{\text{training examples}}{\text{batch size}} \right\rceil, \qquad \text{total iterations} = \text{epochs} \times \text{iterations per epoch}
$$

::::example[Count the updates]
A network trains for 5 epochs on 2,500 examples with a batch size of 200. How many weight updates does it make?

:::step
Divide: 2,500 / 200 = 12.5. Twelve full batches use 2,400 examples, and the remaining 100 form a 13th batch, so each epoch has 13 iterations.
:::

:::step
Multiply by the number of epochs: 13 × 5 = 65.
:::

:::answer
The network makes 65 weight updates. Rounding down to 12 per epoch, or multiplying 12.5 by 5, are the two common mistakes.
:::
::::

Some training setups drop an incomplete final batch instead; a question that intends this will say so. More epochs mean more passes over the same data: too few leave the network underfit, and too many let it memorize the training set, which is why training often stops early once validation loss stops improving (lesson 5.6).

::check{id="nn-training-03"}

:::takeaways
- A neuron computes z = w1x1 + w2x2 + ... + b, then applies an activation function. Weights scale the inputs; the bias shifts the threshold, like an intercept.
- A step neuron with weights 1 and 1 computes AND with bias -1.5 and OR with bias -0.5. One neuron draws one straight line, so a single perceptron (Rosenblatt, 1958) cannot compute XOR; a hidden layer fixes it.
- A neural network has an input layer (one node per feature), hidden layers, and an output layer. In a dense layer every neuron connects to every output of the layer before.
- Ranges: step 0 or 1, sigmoid 0 to 1, tanh -1 to 1, ReLU 0 to infinity. Softmax turns class scores into probabilities that sum to 1. Without nonlinear activations, any network collapses into a linear model.
- Parameters in a dense layer: inputs × neurons weights, plus one bias per neuron. Layer sizes are hyperparameters.
- Training loop: forward pass, loss, backpropagation (computes gradients with the chain rule), update (gradient descent). Inference is the forward pass alone.
- Vanishing gradients: small sigmoid slopes multiply across layers and starve the early layers; ReLU's slope of 1 helps.
- Epoch: one pass through the data. Batch size: examples per update. Iteration: one update. Iterations per epoch = examples / batch size, rounded up.
:::
