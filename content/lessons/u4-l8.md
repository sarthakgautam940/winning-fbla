R is the other major language of data science, and one objective asks you to discuss its use. Questions test R's distinctive syntax (assignment with `<-`, counting from 1), the tidyverse verbs, ggplot2's grammar of graphics, the tools around R, and when R is the better choice than Python. If you already know Python, the most valuable thing to learn here is where R behaves differently, because that is where test writers set their traps.

## What R is for

**R**, often called the **R language**, is a programming language and environment built for statistical computing and graphics. Ross Ihaka and Robert Gentleman created it at the University of Auckland in New Zealand as a version of an older statistics language called S. They first announced it in 1993, and R 1.0.0 was released in 2000. R is free and open source.

R was designed by statisticians for statisticians, and it shows. Statistical tests, models, and distributions are built in, and its graphics, especially through ggplot2, are known for publication-quality charts. R is widely used in academic research, medicine, public health, economics, and anywhere careful statistical analysis matters.

## Vectors, assignment with <-, and indexing from 1

R's basic unit of data is the **vector**, an ordered set of values of one type. Even a single number is a vector of length 1. The function `c()` (for "combine") builds vectors, and the arrow `<-` assigns a value to a name:

```r
x <- c(10, 20, 30, 40)   # assign a vector to x
x[1]                     # 10: R counts positions from 1
x[2:3]                   # 20 30
x[-1]                    # 20 30 40: a negative index REMOVES that position
x * 2                    # 20 40 60 80: arithmetic is element by element
mean(x)                  # 25
```

Three habits separate R from Python:

- **Assignment uses `<-`.** (`=` also works in most places, but `<-` is the R convention.)
- **Indexing starts at 1**, so `x[1]` is the first element. In Python, the first element is `x[0]`.
- **A negative index removes an element.** In R, `x[-1]` means "everything except the first element." In Python, `x[-1]` means the last element.

Like NumPy arrays, R vectors are **vectorized**: `x * 2` doubles every element, with no loop. R's statistics functions work directly on vectors: `mean()`, `median()`, `sd()`, `var()`, `sum()`, `length()`, and `summary()`. Note that `sd()` and `var()` divide by n - 1, giving the **sample** standard deviation and variance (lesson 2.3).

:::trap
**Common trap.** Students who know Python read `x[2]` as the third element. In R it is the second, because R counts from 1.
:::

## Data frames, factors, and NA

A **data frame** is R's table: a list of equal-length column vectors, one row per observation, much like a pandas DataFrame. The `$` operator pulls out a column:

```r
students <- data.frame(
  name  = c("Ava", "Ben", "Chloe"),
  grade = c(10, 11, 12),
  gpa   = c(3.6, NA, 3.9)
)
students$gpa        # the gpa column, as a vector
students[1, ]       # the first row, all columns
nrow(students)      # 3
```

Square brackets take a row position and a column position, separated by a comma; leaving one side empty means "all."

A **factor** is R's type for categorical data: a vector stored with a fixed set of allowed values called **levels**, such as "low", "medium", and "high". Models and charts treat factors as categories rather than as text or numbers.

**NA** is R's marker for a missing value, like NULL in SQL and NaN in pandas. Missing values spread through calculations:

```r
mean(c(4, NA, 8))                 # NA
mean(c(4, NA, 8), na.rm = TRUE)   # 6
is.na(c(4, NA, 8))                # FALSE TRUE FALSE
```

The argument `na.rm = TRUE` ("NA remove") tells a function to skip missing values, and `is.na()` finds them.

## Packages and CRAN

R's power comes from add-on **packages**. Most are distributed through **CRAN**, the Comprehensive R Archive Network, a network of mirror servers around the world that carry identical copies of R and its packages. CRAN was first announced in 1997, and it now lists more than 25,000 packages.

Using a package takes two different steps:

```r
install.packages("dplyr")   # download and install once per computer
library(dplyr)              # load it in each new session
```

`install.packages()` downloads the package from CRAN one time. `library()` makes an installed package available in the current session, and it must run again every time R restarts.

## The tidyverse: dplyr verbs and pipes

The **tidyverse** is a collection of R packages that share one design: data in tidy form (lesson 1.7), small functions named with verbs, and steps chained together. Its best-known members are **dplyr** for data manipulation, **ggplot2** for charts, **tidyr** for reshaping, and **readr** for reading files.

dplyr's core verbs each do one job, and each has a SQL counterpart:

| dplyr verb | What it does | SQL counterpart |
|---|---|---|
| `filter()` | Keeps rows that meet a condition | WHERE |
| `select()` | Keeps chosen columns | SELECT column list |
| `mutate()` | Adds or changes columns | A computed column in SELECT |
| `arrange()` | Sorts rows (`desc()` for descending) | ORDER BY |
| `group_by()` | Groups rows for later steps | GROUP BY |
| `summarise()` | Collapses each group to summary values | Aggregates such as AVG and COUNT |

A **pipe** passes the result of one step into the next, so a chain reads like a recipe from top to bottom. R has two pipes: `%>%`, from the magrittr package (2014), and the native `|>`, built into R since version 4.1.0 (2021). Both turn `x |> f(y)` into `f(x, y)`. Read each pipe as "then":

```r
students |>
  filter(grade >= 11) |>
  group_by(grade) |>
  summarise(avg_gpa = mean(gpa, na.rm = TRUE))
```

Take the students, *then* keep grades 11 and 12, *then* group by grade, *then* compute each grade's average GPA. The result has one row per grade.

**tidyr** reshapes data: `pivot_longer()` turns wide data into long data, and `pivot_wider()` does the reverse, like pandas' melt and pivot_table (lesson 4.6).

## ggplot2 and the grammar of graphics [Competitive]

**ggplot2**, created by Hadley Wickham and first released in 2007, builds charts from a **grammar of graphics**, an idea from Leland Wilkinson's book *The Grammar of Graphics*. Instead of choosing a chart type from a menu, you describe a chart in parts and add them together with `+`:

```r
ggplot(students, aes(x = grade, y = gpa)) +
  geom_point() +
  labs(title = "GPA by grade")
```

- The **data** is the data frame, `students`.
- **Aesthetic mappings**, written inside `aes()`, connect variables to visual properties: x position, y position, color, size, and shape.
- **Geoms** are the marks that draw the data: `geom_point()` for a scatterplot, `geom_histogram()`, `geom_boxplot()`, `geom_line()`, and `geom_bar()`.
- Further layers add **facets** (`facet_wrap()` for small multiples), **scales**, **labels**, and **themes**.

Because each part is separate, changing a scatterplot into a boxplot means swapping one geom, and coloring points by a variable means adding `color = club` inside `aes()`.

:::tip
**Test tip.** ggplot2 joins layers with `+`; dplyr chains steps with a pipe (`|>` or `%>%`). A question showing `+` between `geom_` functions is about building one chart, not about passing data along.
:::

## RStudio, R Markdown, Quarto, and choosing R or Python

Most people write R in **RStudio**, an integrated development environment (IDE) with panes for code, the console, plots, and data. The company behind it renamed itself **Posit** in 2022, but the IDE kept the RStudio name. Three more tools come up:

- **R Markdown** documents mix narrative text, code, and the code's output, and render to HTML, PDF, or Word, so a report updates itself when the data changes.
- **Quarto**, from Posit, is a newer publishing system that does the same for Python, R, Julia, and Observable code.
- **Shiny** is an R package for building interactive web apps and dashboards in R.

R or Python? Both handle most data science work, and many teams use both.

| Choose R when | Choose Python when |
|---|---|
| The work centers on statistics, statistical tests, and modeling | The work is part of a larger software product or pipeline |
| You want publication-quality charts with ggplot2 | You need deep learning (PyTorch, TensorFlow) |
| The team or field already works in R, as in much of academia and public health | You need a general-purpose language for automation, web services, or deployment |

Outside programming languages, analysts also use **Excel** for small, quick analyses, **Tableau** and **Power BI** for interactive business dashboards, and **Apache Spark** for data too large for one computer (lesson 4.7).

:::takeaways
- R is a language for statistical computing and graphics, created by Ross Ihaka and Robert Gentleman (University of Auckland) as a version of S; announced 1993, version 1.0.0 in 2000.
- Assignment uses <-. Vectors are built with c(). Indexing starts at 1, and a negative index removes elements (x[-1] drops the first). Arithmetic is vectorized.
- sd() and var() use n - 1. Data frames are R's tables; df$col picks a column; factors store categories with levels; NA marks missing values, skipped with na.rm = TRUE.
- install.packages() downloads a package from CRAN once; library() loads it each session. CRAN lists more than 25,000 packages.
- dplyr verbs: filter (rows), select (columns), mutate (new columns), arrange (sort), group_by and summarise (grouped summaries). Pipes |> and %>% pass results along; read them as "then."
- ggplot2 builds charts from data, aes() mappings, and geoms, joined with +. tidyr's pivot_longer and pivot_wider reshape data.
- RStudio is the main R IDE (from Posit); R Markdown and Quarto make reproducible reports; Shiny builds web apps.
- Choose R for statistics-heavy work and graphics; choose Python for deep learning, production systems, and general-purpose programming.
:::
