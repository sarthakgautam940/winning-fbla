Should you buy the warranty? Is a game worth playing? How many customers will answer a campaign? Expected value answers each of these with one weighted average, and calculating it is an official objective of this event. This lesson builds the idea from the ground up: random variables and the tables that describe them, expected value and its rules, the named distributions you should recognize on sight, and the vocabulary for the variables in a study.

## Random variables, discrete and continuous

A **random variable** is a number whose value depends on the outcome of a random process. It is usually named with a capital letter such as X. The number of heads in 3 coin flips is a random variable that can be 0, 1, 2, or 3. So are the number of customers who enter a store in an hour and the time a web page takes to load.

Random variables come in two types, matching the numeric data types from lesson 1.3:

- A **discrete variable** takes separate, countable values with gaps between them, such as 0, 1, 2, 3. Counts are discrete: heads, customers, defective parts, goals.
- A **continuous variable** can take any value in an interval, such as any time between 0 and 10 seconds. Measurements are continuous: time, height, weight, temperature, distance.

A quick test: ask whether the values are counted or measured. Counted values are discrete; measured values are continuous.

:::trap
**Common trap.** Decimals do not make a variable continuous. Shoe sizes come in steps of a half (8, 8.5, 9), so shoe size as sold is discrete: no size exists between 8 and 8.5. And the average of a discrete variable need not be one of its values. A class can average 2.4 siblings per student, though no student has 2.4 siblings.
:::

For a continuous variable, probability lives in intervals, not single points. It is the area under a curve over an interval, as with the normal curve in lesson 2.5, and the probability of any one exact value is 0. The height of the curve at a point is not itself a probability; only areas are. The chance that a page loads in exactly 2.000000 seconds is 0, while the chance that it loads in between 1.9 and 2.1 seconds can be large. As a result, for a continuous X, P(X < a) and P(X ≤ a) are equal.

## Probability distributions: tables that sum to 1

The **probability distribution** of a discrete random variable lists every possible value together with its probability. A factory records X, the number of defective items in a box:

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P(X = x) | 0.50 | 0.30 | 0.15 | 0.05 |

```figure
type: bar
caption: The distribution of defects per box. The bar heights are probabilities, so together they add up to 1.
xLabel: Defective items in a box
yLabel: Probability
categories: ["0", "1", "2", "3"]
series:
  - values: [0.50, 0.30, 0.15, 0.05]
```

Every valid probability distribution follows two rules:

1. Every probability is between 0 and 1.
2. The probabilities add up to exactly 1.

The rules let you fill in a missing probability: it is 1 minus the sum of the others. They also expose an invalid table, such as one with a negative entry or one whose entries add up to 0.9 or 1.1.

A **cumulative probability** adds up a range of values:

- P(X ≤ 1) = 0.50 + 0.30 = 0.80, the chance of **at most** 1 defect.
- P(X ≥ 2) = 0.15 + 0.05 = 0.20, the chance of **at least** 2. As a check, it equals 1 - P(X ≤ 1).
- P(X < 2) means 0 or 1 defects, so it also equals 0.80.

:::tip
**Test tip.** Translate the words before you add. "At most 2" means 0, 1, or 2. "Fewer than 2" means 0 or 1. "At least 2" means 2 or more. For a discrete variable, the difference between < and ≤ changes the answer.
:::

::check{id="rv-dist-01"}

## Expected value as a weighted average

The **expected value** of a random variable, written E(X) or $$\mu$$, is the long-run average of X over many repetitions. It is a weighted average: multiply each value by its probability, then add.

$$
E(X) = \sum x \cdot P(X = x)
$$

::::example[Expected defects per box]
Find the expected number of defective items per box from the table above.

:::step
Multiply each value by its probability: 0 × 0.50 = 0, 1 × 0.30 = 0.30, 2 × 0.15 = 0.30, and 3 × 0.05 = 0.15.
:::

:::step
Add the products: 0 + 0.30 + 0.30 + 0.15 = 0.75.
:::

:::answer
E(X) = 0.75 defective items per box. Over many boxes the factory should average about 0.75 defects per box, even though no single box can hold 0.75 defects.
:::
::::

Two classic results are worth memorizing. For a fair die, each face has probability 1/6, so E(X) = (1 + 2 + 3 + 4 + 5 + 6) / 6 = 21/6 = 3.5. For the sum of two dice, the expected value is 3.5 + 3.5 = 7, for a reason the Champion section explains.

:::trap
**Common trap.** Do not average the values without their probabilities. The plain average of 0, 1, 2, and 3 is 1.5, but the expected number of defects is 0.75 because the low values are far more likely. The expected value is also not the most likely value: here the most likely value is 0.
:::

::check{id="expected-value-01"}

## Expected value in games, insurance, and decisions

Expected value turns an uncertain choice into a single number. For a game or a bet, find the expected prize, then subtract the cost:

$$
\text{expected net winnings} = E(\text{prize}) - \text{cost}
$$

::::example[Is this game worth playing?]
A game costs $2 to play. You roll a fair die and win $10 if it shows a 6, and nothing otherwise. What are your expected net winnings?

:::step
The prize is $10 with probability 1/6 and $0 with probability 5/6, so E(prize) = 10 × 1/6, about $1.67.
:::

:::step
Subtract the cost: $1.67 minus $2.00 leaves an expected loss of about $0.33.
:::

:::answer
On average you lose about 33 cents per play, so over 300 plays you should expect to lose about $100. The game would be fair at a price of about $1.67.
:::
::::

A game is **fair** when its expected net winnings are exactly 0. Casino games and lotteries give players negative expected net winnings, and that gap is the house's profit.

**Insurance and warranties** work the same way from the seller's side. An insurer charges each customer more than that customer's expected claim, so across many customers it collects more than it pays out. As a buyer, compare the price with the expected cost it covers. A $60 warranty against a $300 repair that is needed with probability 0.15 covers an expected 0.15 × $300 = $45, so on expected value alone it is a poor deal. People still buy insurance against rare, large losses they could not afford to absorb, which can be sensible even when the expected value is negative.

**Comparing options.** To choose between uncertain options, compare their expected values. A guaranteed $50 or a 30% chance at $200? The gamble's expected value is 0.3 × $200 = $60, so it is better on average, though riskier.

**Expected counts.** If each of n independent trials succeeds with probability p, the expected number of successes is n × p. If 2,000 people visit a site and each buys with probability 0.03, the site should expect 2,000 × 0.03 = 60 buyers.

## Linearity of expectation and variance of a random variable [Champion]

Expected values follow two rules that save time on the test.

- **Shifting and scaling:** E(aX + b) = a E(X) + b. If the expected noon temperature in Celsius is 20 degrees, then since Fahrenheit is F = 1.8C + 32, the expected temperature in Fahrenheit is 1.8 × 20 + 32 = 68 degrees.
- **Sums:** E(X + Y) = E(X) + E(Y), always, whether or not X and Y are independent. That is why two dice have an expected sum of 3.5 + 3.5 = 7.

The **variance of a random variable** measures its spread around E(X). Each squared deviation is weighted by its probability:

$$
\text{Var}(X) = \sum (x - \mu)^2 \cdot P(X = x)
$$

The standard deviation is the square root of the variance. A shortcut often makes the arithmetic easier: $$\text{Var}(X) = E(X^2) - \mu^2$$, the mean of the squares minus the square of the mean.

::::example[Variance of the defects]
Find the variance and standard deviation of X, the defects per box, where $$\mu = 0.75$$.

:::step
Find $$E(X^2)$$ by squaring each value before weighting it: 0 × 0.50 + 1 × 0.30 + 4 × 0.15 + 9 × 0.05 = 0 + 0.30 + 0.60 + 0.45 = 1.35.
:::

:::step
Subtract the squared mean: $$1.35 - 0.75^2 = 1.35 - 0.5625 = 0.7875$$.
:::

:::step
Take the square root: $$\sqrt{0.7875} \approx 0.887$$.
:::

:::answer
Var(X) = 0.7875, and the standard deviation is about 0.89 defective items.
:::
::::

The rules for spread match what you learned for data in lesson 2.3:

- $$\text{Var}(aX + b) = a^2\,\text{Var}(X)$$, so the standard deviation of aX + b is |a| times the standard deviation of X. Adding a constant shifts every value equally and leaves the spread alone; multiplying by a stretches every distance by |a|.
- For **independent** X and Y, Var(X + Y) = Var(X) + Var(Y), and the same is true of Var(X - Y). Variances add; standard deviations do not. If X and Y have standard deviations 6 and 8, the standard deviation of X + Y is $$\sqrt{36 + 64} = 10$$, not 14.

:::trap
**Common trap.** The rule for sums of expected values needs no independence: E(X + Y) = E(X) + E(Y) always. The rule for sums of variances holds only when X and Y are independent.
:::

## Distributions to recognize: uniform, binomial, Poisson, normal [Competitive]

A few distributions appear so often that they have names. Expect to recognize them from a one-sentence description and to know their means.

| Distribution | Type | What it describes | Mean | Variance |
|---|---|---|---|---|
| Uniform | Discrete or continuous | Every value, or every interval of the same width, is equally likely | (a + b) / 2 on [a, b] | (b - a)² / 12 if continuous |
| Binomial | Discrete | Number of successes in n independent trials, each with success probability p | np | np(1 - p) |
| Poisson | Discrete | Number of events in a fixed interval of time or space, at a constant average rate $$\lambda$$ | $$\lambda$$ | $$\lambda$$ |
| Normal | Continuous | A measurement that clusters symmetrically around its mean | $$\mu$$ | $$\sigma^2$$ |

The **binomial distribution** has four conditions: a fixed number of trials n, two outcomes per trial (success or failure), independent trials, and the same probability of success p on every trial. The probability of exactly k successes is:

$$
P(X = k) = C(n, k)\, p^k (1 - p)^{n - k}
$$

Here C(n, k) counts the ways to choose which k of the n trials are the successes (lesson 2.7).

::::example[Exactly 2 sixes in 3 rolls]
A fair die is rolled 3 times. What is the probability of exactly 2 sixes?

:::step
This is binomial with n = 3, p = 1/6, and k = 2. The 2 sixes can fall on C(3, 2) = 3 pairs of rolls: first and second, first and third, or second and third.
:::

:::step
Each of those sequences has probability (1/6) × (1/6) × (5/6) = 5/216.
:::

:::step
Multiply by the number of sequences: 3 × 5/216 = 15/216, about 0.069.
:::

:::answer
P(exactly 2 sixes) = 15/216, about 0.069.
:::
::::

The **Poisson distribution** counts events that have no fixed upper limit: emails per hour, typos per page, visitors per minute. Its signature is that the mean and the variance are equal. If a help desk averages 4 calls per hour, the variance of the hourly count is also 4, so its standard deviation is 2.

A **uniform distribution** makes every outcome equally likely. A fair die is discrete uniform. A bus that is equally likely to arrive at any moment in the next 20 minutes is continuous uniform on [0, 20], with mean (0 + 20) / 2 = 10 minutes. The **normal distribution** (lesson 2.5) is the continuous bell curve.

:::tip
**Test tip.** Ask, "Is there a fixed number of trials, each a success or a failure?" If so, it is binomial. If X counts events over time or space with no fixed maximum, it is Poisson. If every outcome is equally likely, it is uniform. If X is a measurement that clusters symmetrically, it is normal.
:::

## Types of variables in a study [Competitive]

Studies and models describe their variables with a second vocabulary, and test questions use all of it.

- The **explanatory variable** is the one thought to influence the outcome. In an experiment it is the variable the researcher changes, called the **independent variable**. In machine learning it is called a feature or predictor.
- The **response variable** is the outcome being measured. It is also called the **dependent variable** and, in machine learning, the target.
- A **confounding variable** is related to both the explanatory and the response variable, so it can create or hide an association between them. Ice cream sales and drownings rise together because both rise in hot weather; temperature is the confounder. Lesson 3.3 covers confounding in depth.
- **Quantitative** variables are numeric, either discrete or continuous. **Qualitative** variables are categorical (lesson 1.3).

In a study of whether daily screen time affects hours of sleep, screen time is the explanatory variable and hours of sleep is the response. Age could be a confounder, since it may be linked to both screen time and sleep.

:::trap
**Common trap.** An "independent variable" and "independent events" (lesson 2.7) are different ideas. An independent variable is the input a researcher sets or the predictor a model uses; independent events are events that do not change each other's probabilities.
:::

:::takeaways
- A random variable is a numerical outcome of a random process. Discrete variables are counted and take separate values; continuous variables are measured and can take any value in an interval.
- For a continuous X, P(X = a) = 0 for every exact value a, so P(X < a) = P(X ≤ a).
- A probability distribution lists each value with its probability. Every probability is from 0 to 1, and together they sum to 1, so a missing probability is 1 minus the rest.
- E(X) = sum of x × P(x), the long-run average. A fair die gives 3.5 and two dice give 7. The expected value need not be a possible value.
- Expected net winnings = E(prize) - cost, and a fair game has expected net winnings of 0. The expected number of successes in n trials is np.
- E(aX + b) = aE(X) + b, and E(X + Y) = E(X) + E(Y) always. Var(aX + b) = a² Var(X). For independent X and Y, variances add; standard deviations do not.
- Binomial: fixed n, two outcomes, independent trials, same p; mean np and variance np(1 - p). Poisson: counts in an interval, with mean = variance. Uniform on [a, b]: mean (a + b) / 2.
- Explanatory (independent) variables influence response (dependent) variables, and a confounder is linked to both.
:::
