Logic is the oldest way of giving AI knowledge it can reason with exactly: if the facts are true and the rules are sound, the conclusions are guaranteed. Two objectives ask you to explain how predicate logic is used in AI and to give examples of it. This lesson builds the language from the ground up, starting with propositional logic and its truth tables and ending with predicates and quantifiers. Lesson 7.4 then shows how to translate English into logic and reason with it.

## Propositions and connectives

A **proposition** is a statement that is either true or false: "It is raining" or "Ava is in the Robotics club." Questions and commands are not propositions. **Propositional logic** gives each proposition a letter, such as P, Q, or R, and combines them with five **connectives**:

| Connective | Symbol | Read as | True when |
|---|---|---|---|
| Negation | $$\neg P$$ | not P | P is false |
| Conjunction | $$P \land Q$$ | P and Q | both are true |
| Disjunction | $$P \lor Q$$ | P or Q | at least one is true |
| Implication (conditional) | $$P \rightarrow Q$$ | if P then Q | in every case except P true and Q false |
| Biconditional | $$P \leftrightarrow Q$$ | P if and only if Q | both have the same value |

Logical "or" is **inclusive**: P ∨ Q is true when both are true. (The exclusive or, true when exactly one is true, is XOR, which you met in lesson 5.9.) As in arithmetic, there is an order of operations: negation applies first, then AND, then OR, then the two arrows. Parentheses make the order explicit.

::::example[Evaluate a compound statement]
Let P be true, Q be true, and R be false. What is the truth value of $$\neg P \lor (Q \land R)$$?

:::step
Evaluate the negation: P is true, so ¬P is false.
:::

:::step
Evaluate the parentheses: Q ∧ R is true ∧ false, which is false.
:::

:::step
Combine with OR: false ∨ false is false.
:::

:::answer
The statement is false. Neither side of the OR is true.
:::
::::

::check{id="prop-logic-01"}

## Truth tables and the conditional

A **truth table** lists every combination of truth values for the variables and the value of an expression in each row. Each variable is true (T) or false (F), so n variables give $$2^n$$ rows: 4 rows for two variables, 8 for three.

The connective that trips people up is the implication, P → Q. It makes a promise: whenever P is true, Q is true too. The only way to break the promise is for P to be true while Q is false.

| P | Q | P → Q | ¬Q → ¬P |
|---|---|---|---|
| T | T | T | T |
| T | F | F | F |
| F | T | T | T |
| F | F | T | T |

The last two rows surprise most students: when P is false, P → Q is true whatever Q is. "If 2 + 2 = 5, then the moon is made of cheese" is true in logic, because its condition is false; such an implication is called **vacuously true**. Logic also does not require the two parts to be related. The biconditional $$P \leftrightarrow Q$$ is stricter than the implication: it is true only when P and Q match.

A **tautology** is true in every row, such as P ∨ ¬P. A **contradiction** is false in every row, such as P ∧ ¬P.

:::trap
**Common trap.** P → Q is false in only one row: P true, Q false. A false condition never makes an implication false.
:::

::check{id="prop-logic-02"}

## Equivalences: contrapositive and De Morgan [Competitive]

Two expressions are **logically equivalent** when they have the same value in every row of the truth table. A few equivalences come up again and again.

From the implication P → Q you can build three related statements:

| Name | Form | "If it rains, the game is canceled" becomes | Equivalent to the original? |
|---|---|---|---|
| Converse | $$Q \rightarrow P$$ | If the game is canceled, it rained. | No |
| Inverse | $$\neg P \rightarrow \neg Q$$ | If it does not rain, the game is not canceled. | No |
| Contrapositive | $$\neg Q \rightarrow \neg P$$ | If the game is not canceled, it did not rain. | Yes |

The table in the previous section shows the contrapositive matching the original in every row. The converse and the inverse are equivalent to each other (each is the other's contrapositive) but not to the original. Two more equivalences complete the toolkit:

- An implication can be rewritten as a disjunction: $$P \rightarrow Q \equiv \neg P \lor Q$$.
- Its negation says the promise was broken: $$\neg(P \rightarrow Q) \equiv P \land \neg Q$$.

**De Morgan's laws** move a negation inside parentheses by negating each part and flipping AND and OR:

$$
\neg(P \land Q) \equiv \neg P \lor \neg Q \qquad \neg(P \lor Q) \equiv \neg P \land \neg Q
$$

In English: "It is not both raining and windy" means "it is not raining, or it is not windy." "It is neither raining nor windy" means "it is not raining, and it is not windy."

::check{id="prop-logic-03"}

## Why we need predicates

Propositional logic treats each statement as an indivisible unit, and that is its limit. Suppose you want to say that every student at the school takes math. You would need a separate proposition for each student, "Ava takes math," "Ben takes math," and so on, and you still could not state the general rule or reason about a student you had not listed. Propositional logic cannot look inside a statement to see who or what it is about.

**Predicate logic**, also called **first-order logic** (FOL), extends propositional logic with objects, properties, relations, variables, and quantifiers, so it can state facts about particular things and general rules about all or some of them. "Every student takes math" becomes one sentence:

$$
\forall x\, (\text{Student}(x) \rightarrow \text{TakesMath}(x))
$$

It reads, "for every x, if x is a student, then x takes math."

::check{id="fol-syntax-04"}

## Constants, variables, predicates, functions

Predicate logic sentences are built from a few kinds of parts. The examples come from the course's sample school database.

| Part | What it does | Examples |
|---|---|---|
| **Constant** | Names one specific object | Ava, Robotics, MsPark, 3 |
| **Variable** | Stands for any object | x, y, z |
| **Predicate** | A property or relation that is true or false of its arguments | Student(Ava), MemberOf(Ava, Robotics) |
| **Function** | Maps objects to an object (not to true or false) | AdvisorOf(Robotics), which is MsPark; GPA(Ava), which is 3.6 |

The number of arguments a predicate or function takes is its **arity**. Student(x) has arity 1, MemberOf(x, y) has arity 2, and Teaches(x, subject, day) has arity 3.

The difference between a predicate and a function is what they produce. MemberOf(Ava, Robotics) is a claim, true or false. AdvisorOf(Robotics) is an object, a person, so it can sit inside a predicate: Teaches(AdvisorOf(Robotics), Math) says that the Robotics advisor teaches math. Functions can nest, too: AdvisorOf(ClubOf(Ava)) is the advisor of Ava's club.

A predicate applied to its arguments is an **atomic sentence**, and atomic sentences combine with the connectives into larger ones: MemberOf(Ava, Robotics) ∧ Advises(MsPark, Robotics).

## Quantifiers: for all, there exists

Quantifiers let a sentence talk about all objects or some objects without naming them.

- The **universal quantifier** $$\forall$$ means "for all" or "every." $$\forall x\, (\text{Student}(x) \rightarrow \text{TakesMath}(x))$$ says every student takes math.
- The **existential quantifier** $$\exists$$ means "there exists" or "some," that is, at least one. $$\exists x\, (\text{Student}(x) \land \text{InClub}(x, \text{Chess}))$$ says at least one student is in the chess club.

Notice the connectives inside: the universal statement uses an implication, and the existential statement uses AND. That pairing is the most important habit in translating English into logic, and lesson 7.4 explains why the other combinations go wrong. A variable that a quantifier covers is **bound**; in a complete sentence every variable is bound.

::check{id="fol-syntax-06"}

## How predicate logic is used in AI

Predicate logic gives AI a precise, unambiguous language for knowledge, and many systems are built on it:

- **Knowledge bases and expert systems** store facts, such as MemberOf(Ava, Robotics), and rules, such as "every member of a club with a competition must register," and an inference engine derives new facts from them (lesson 7.5).
- **Logic programming** languages such as Prolog write programs as facts and rules. The rule below says that X is a grandparent of Z if X is a parent of some Y who is a parent of Z.

```text
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
```

- **Automated theorem provers** check mathematical proofs and verify that software and computer chips behave as designed.
- **Planning systems** describe states, actions, and goals in logic to work out how to reach a goal (lesson 7.8).
- **Ontologies and knowledge graphs** rest on logic with formally defined meaning (lesson 7.2).

Logic's strengths are precision, explainability, and certainty: from true facts and sound rules, every conclusion is guaranteed and can be traced step by step. Its weaknesses are brittleness and an all-or-nothing view of truth: every rule must be written by hand, exceptions break it, and it has no built-in way to say that something is merely likely. Lesson 7.6 compares it with probability-based reasoning, which handles uncertainty.

::check{id="fol-syntax-08"}

:::takeaways
- A proposition is a statement that is true or false. Connectives: ¬ (not), ∧ (and), ∨ (inclusive or), → (if-then), and $$\leftrightarrow$$ (if and only if). Truth tables have 2ⁿ rows for n variables.
- P → Q is false only when P is true and Q is false; a false condition makes it vacuously true. $$P \leftrightarrow Q$$ is true when both match.
- The contrapositive (¬Q → ¬P) is equivalent to P → Q; the converse (Q → P) and inverse (¬P → ¬Q) are not, though they are equivalent to each other. P → Q ≡ ¬P ∨ Q, and ¬(P → Q) ≡ P ∧ ¬Q.
- De Morgan: ¬(P ∧ Q) ≡ ¬P ∨ ¬Q, and ¬(P ∨ Q) ≡ ¬P ∧ ¬Q.
- Propositional logic cannot express general rules about many objects; predicate (first-order) logic adds constants, variables, predicates, functions, and quantifiers.
- Predicates are true or false (MemberOf(Ava, Robotics)); functions return objects (AdvisorOf(Robotics)). Arity is the number of arguments.
- ∀ means "for all" and pairs with →; ∃ means "there exists" and pairs with ∧.
- AI uses predicate logic in knowledge bases, expert systems, Prolog, theorem provers, and planning: precise and explainable, but brittle and unable to express uncertainty.
:::
