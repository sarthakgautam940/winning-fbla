How does a model actually learn? It measures how wrong it is with a loss function, then nudges its parameters, step by step, in the direction that makes it less wrong. That procedure, gradient descent, trains everything from a simple regression to the largest neural networks. Test questions ask which loss fits a task, what goes wrong with a bad learning rate, how the batch variants differ, and, at the champion level, what one update step produces. The arithmetic is light; the ideas are what matter.

## Loss functions: MSE and cross-entropy

A **loss function** (also called a cost function) turns a model's mistakes into a single number: the bigger the number, the worse the predictions. **Training** means searching for the parameter values that make the loss as small as possible.

The right loss depends on the task:

- For **regression**, the standard loss is **mean squared error** (MSE), the average of the squared differences between predictions and true values (lesson 3.8). Squaring makes large errors count heavily.
- For **classification**, the standard loss is **cross-entropy** (also called **log loss**). For each example, it takes the probability the model gave to the *correct* class, p, and charges $$-\ln(p)$$.

Cross-entropy rewards confident correct predictions and punishes confident wrong ones severely. If the true class is "spam":

| Model's probability for "spam" | Loss, $$-\ln(p)$$ |
|---|---|
| 0.9 (confident and right) | about 0.11 |
| 0.5 (unsure) | about 0.69 |
| 0.1 (confident and wrong) | about 2.30 |

A perfect prediction (p = 1) has a loss of 0. Training a logistic regression or a classification network means making these losses small across all the training examples.

:::tip
**Test tip.** Predicting a number points to MSE (or MAE). Predicting a class with probabilities points to cross-entropy. Accuracy is a way to report results, not a loss that gradient descent can minimize, because it does not change smoothly as the weights change.
:::

## Gradient descent in one picture

**Gradient descent** is an optimization algorithm that minimizes a loss by repeatedly adjusting the parameters a small step in the direction that lowers the loss fastest. Picture standing on a hillside in thick fog: you cannot see the valley, but you can feel which way the ground slopes under your feet, so you take a step downhill, feel again, and repeat.

The **gradient** is that slope: for each parameter, it says how much the loss would change if the parameter increased slightly. Gradient descent moves each parameter **against** its gradient:

$$
w_{\text{new}} = w - \eta \times \text{gradient}
$$

where $$\eta$$ (eta) is the learning rate. If the gradient is positive, increasing w would raise the loss, so the update decreases w; if the gradient is negative, the update increases w.

A loss shaped like a single bowl, as MSE is for linear regression, has one minimum, and gradient descent with a sensible learning rate will reach it. The loss surface of a neural network is bumpier: it can have **local minima** (dips that are not the lowest point) and flat regions where progress stalls. In practice, large networks still train well, but gradient descent finds a good solution, not a guaranteed best one.

## The learning rate

The **learning rate** is the size of each step, and it is a hyperparameter (lesson 5.1):

- **Too small**: each step barely moves, so training needs a very large number of iterations.
- **Too large**: steps overshoot the minimum and bounce from side to side. If it is large enough, each bounce lands higher than the last and the loss grows, a failure called **divergence**.
- **Well chosen**: the loss falls quickly and steadily.

Many training runs use a **learning rate schedule** that starts larger and shrinks over time, so early steps cover ground and later steps settle precisely.

## Batch, stochastic, and mini-batch [Competitive]

Gradient descent can compute each step's gradient from different amounts of data:

- **Batch gradient descent** uses the entire training set for every step. Its steps are accurate but slow to compute when the dataset is large.
- **Stochastic gradient descent** (SGD) uses a single randomly chosen example for each step. Steps are fast but noisy; the noise makes the path zigzag, which can help it escape shallow local minima.
- **Mini-batch gradient descent** uses a small group of examples, such as 32 or 64, for each step. It balances accuracy and speed, and GPUs process a mini-batch in parallel, which makes it the standard choice in deep learning.

One full pass through the training data is an **epoch**. With 1,000 training examples and mini-batches of 100, each epoch makes 1,000 / 100 = 10 updates (lesson 5.9 counts these in more detail).

## Linear and logistic regression as learners

The regression models of Unit 3 are learners too, and their training is exactly this process.

A **linear regression** predicts $$\hat{y} = w_1 x_1 + w_2 x_2 + b$$, with a weight for each feature and a bias b (the intercept). With $$w_1 = 2$$, $$w_2 = -1$$, $$b = 5$$, and the input (3, 4), the prediction is 2 × 3 - 1 × 4 + 5 = 7. Training adjusts the weights and the bias to minimize MSE, using gradient descent or an exact formula.

A **logistic regression** computes the same kind of score, $$z = w_1 x_1 + \cdots + b$$, and passes it through the sigmoid to get a probability (lesson 3.6). It is trained by minimizing cross-entropy. Its **decision boundary**, where the model is exactly undecided, is where z = 0, because the sigmoid of 0 is 0.5. With one feature and z = 2x - 6, the boundary is at x = 3: larger x values are predicted as class 1, smaller ones as class 0. With two features, the boundary is a straight line, which is why logistic regression is called a **linear classifier**.

In every case, training changes only the **parameters**, the weights and biases. The data and the features stay fixed.

## One update step by hand [Champion]

A single update shows every piece working together. For one training example, with prediction $$\hat{y} = wx$$ and squared-error loss $$(\hat{y} - y)^2$$, the gradient with respect to w is $$2(\hat{y} - y)x$$.

::::example[One gradient descent update]
A model predicts $$\hat{y} = wx$$. The current weight is w = 3, the training example is x = 2 with true value y = 10, and the learning rate is 0.05. Find the new weight after one step.

:::step
Predict: $$\hat{y} = 3 \times 2 = 6$$. The error is $$\hat{y} - y = 6 - 10 = -4$$, and the loss is $$(-4)^2 = 16$$.
:::

:::step
Gradient: $$2(\hat{y} - y)x = 2 \times (-4) \times 2 = -16$$. It is negative, so increasing w will lower the loss.
:::

:::step
Update: $$w_{\text{new}} = 3 - 0.05 \times (-16) = 3 + 0.8 = 3.8$$.
:::

:::answer
The new weight is 3.8. The new prediction, 3.8 × 2 = 7.6, is closer to 10, and the loss has fallen from 16 to $$(7.6 - 10)^2 = 5.76$$.
:::
::::

Real training repeats this for every example (or every mini-batch) and every parameter, many thousands of times, and in neural networks backpropagation computes the gradients efficiently (lesson 5.9).

::check{id="loss-gd-05"}

:::takeaways
- A loss function scores how wrong predictions are; training minimizes it. MSE fits regression; cross-entropy (log loss) fits classification, charging -ln(p) for the probability given to the true class.
- Gradient descent repeatedly updates each parameter against its gradient: w_new = w - learning rate × gradient. A positive gradient decreases w; a negative one increases it.
- Bowl-shaped (convex) losses have one minimum; neural network losses can have local minima and flat regions.
- Learning rate too small: slow training. Too large: overshooting and possible divergence. Schedules shrink it over time.
- Batch uses all data per step; stochastic uses one example; mini-batch uses small groups (the deep learning standard). An epoch is one full pass through the data.
- Linear regression predicts a weighted sum of the features plus a bias and minimizes MSE; logistic regression applies the sigmoid and minimizes cross-entropy, with its decision boundary where z = 0 (p = 0.5).
- Training adjusts only the parameters (weights and biases). For one example with y-hat = wx, the squared-error gradient is 2(y-hat - y)x.
:::
