Histograms and boxplots are the two charts every data scientist uses to see a distribution, and both are named in the objectives. Test questions put one in front of you and ask what it shows: the shape, where the median falls, the interquartile range, which points are outliers, which group scores higher or varies more. This lesson teaches you to read both at a glance and to know what each one hides.

## Reading a histogram: shape, center, spread

A **histogram** shows the distribution of one numeric variable. The horizontal axis is cut into equal intervals called **bins**, and the height of each bar is the number of values (the **frequency**) in that bin. Some histograms show the proportion or percent in each bin instead, which is called a **relative frequency** histogram.

```figure
type: histogram
caption: Exam scores for 40 students. Most scores fall between 70 and 90, and the 70 to 80 bin is the tallest.
xLabel: Exam score
yLabel: Students
bins:
  - { from: 50, to: 60, count: 2 }
  - { from: 60, to: 70, count: 6 }
  - { from: 70, to: 80, count: 14 }
  - { from: 80, to: 90, count: 12 }
  - { from: 90, to: 100, count: 6 }
```

Read a histogram in three passes:

1. **Shape**: where is the peak, and is one tail longer than the other?
2. **Center**: roughly where is the middle of the data?
3. **Spread**: how wide is the range of values, and are there gaps or isolated bars far from the rest?

You can count straight from the bars. Here 12 + 6 = 18 students scored 80 or higher, and 2 + 6 = 8 scored below 70, which is 8/40 = 20% of the class.

To find the bin that holds the median, add up the counts from the left until you pass the middle position. With 40 values, the median is the average of the 20th and 21st values. The running totals are 2, then 8, then 22, so the 20th and 21st values both sit in the 70 to 80 bin.

:::trap
**Common trap.** A histogram hides the individual values inside each bin, so it can tell you which bin holds the median but not the median's exact value. The same goes for the minimum, the maximum, and the exact mean.
:::

To estimate the mean from a histogram, use each bin's midpoint as a stand-in for the values in it: multiply each midpoint by its count, add, and divide by the total. For the exam scores, (55 × 2 + 65 × 6 + 75 × 14 + 85 × 12 + 95 × 6) / 40 = 3,140 / 40 = 78.5.

## Skewed, symmetric, bimodal, and uniform shapes

Four shapes cover almost every histogram on the test.

A distribution is **skewed right** (positively skewed) when its long tail stretches to the right. A few large values pull the mean above the median. Incomes, home prices, and waiting times are usually skewed right.

```figure
type: histogram
caption: Skewed right. Most callers wait under 20 minutes, but a long tail of long waits pulls the mean above the median.
xLabel: Minutes on hold
yLabel: Callers
bins:
  - { from: 0, to: 10, count: 18 }
  - { from: 10, to: 20, count: 12 }
  - { from: 20, to: 30, count: 7 }
  - { from: 30, to: 40, count: 4 }
  - { from: 40, to: 50, count: 2 }
  - { from: 50, to: 60, count: 1 }
```

A distribution is **skewed left** (negatively skewed) when its long tail stretches to the left. Scores on an easy test are a typical example: most students score high, a few score low, and the mean falls below the median.

```figure
type: histogram
caption: Skewed left. The long tail of low scores pulls the mean below the median.
xLabel: Quiz score (out of 10)
yLabel: Students
bins:
  - { from: 0, to: 2, count: 1 }
  - { from: 2, to: 4, count: 2 }
  - { from: 4, to: 6, count: 4 }
  - { from: 6, to: 8, count: 10 }
  - { from: 8, to: 10, count: 18 }
```

A **symmetric** distribution has two sides that roughly mirror each other, and its mean and median are close. The bell-shaped normal distribution (lesson 2.5) is the most important symmetric shape.

A **bimodal** distribution has two clear peaks. Two peaks usually mean the data mix two different groups, such as the heights of adults and children together, or lunch and dinner crowds in a restaurant's arrival times. When you see one, look for the variable that separates the groups.

A **uniform** distribution has bars of roughly equal height: every range of values is about equally common, as with many rolls of a fair die.

:::tip
**Test tip.** The tail tells the direction. "Skewed right" means the tail is on the right, even though the peak is on the left. The mean follows the tail: right skew puts the mean above the median, and left skew puts it below.
:::

## How bin width changes the picture [Competitive]

The same data can look very different with different bins. Here are the ages of 60 customers at a store that sits between a college and a retirement community, binned two ways:

```figure
type: histogram
caption: Bins 10 years wide. Two clear peaks appear, one in the 20s and 30s and one in the 60s and 70s.
xLabel: Customer age (years)
yLabel: Customers
bins:
  - { from: 20, to: 30, count: 11 }
  - { from: 30, to: 40, count: 17 }
  - { from: 40, to: 50, count: 2 }
  - { from: 50, to: 60, count: 2 }
  - { from: 60, to: 70, count: 12 }
  - { from: 70, to: 80, count: 16 }
```

```figure
type: histogram
caption: The same 60 ages in bins 25 years wide. The two groups merge into one broad mound, and the gap between them disappears.
xLabel: Customer age (years)
yLabel: Customers
bins:
  - { from: 0, to: 25, count: 4 }
  - { from: 25, to: 50, count: 26 }
  - { from: 50, to: 75, count: 28 }
  - { from: 75, to: 100, count: 2 }
```

Bins that are too wide hide real features such as gaps and second peaks. Bins that are too narrow turn random noise into a jagged picture of tiny bars. Neither picture is false, which is why careful analysts try a few bin widths before describing a shape. Software picks a default, but the default is a guess.

## Reading a boxplot: the five-number summary

A **boxplot** (also called a box-and-whisker plot) draws the five-number summary from lesson 2.2: minimum, first quartile (Q1), median, third quartile (Q3), and maximum.

- The **box** runs from Q1 to Q3, so its length is the **interquartile range** (IQR = Q3 - Q1), the spread of the middle half of the data.
- The line inside the box marks the **median**.
- The **whiskers** extend from the box to the smallest and largest values that are not outliers.
- Points beyond the fences, more than 1.5 × IQR below Q1 or above Q3, are drawn as separate dots: the **outliers**.

```figure
type: boxplot
caption: Daily screen time for a group of teenagers. The box spans 2.5 to 5 hours, the median is 3.5, and one value at 11 hours is drawn as an outlier.
axisLabel: Hours per day
groups:
  - { label: Screen time, min: 1, q1: 2.5, median: 3.5, q3: 5, max: 7.5, outliers: [11] }
```

Read this one: the median is 3.5 hours and the IQR is 5 - 2.5 = 2.5 hours. The upper fence is 5 + 1.5 × 2.5 = 8.75, so the value at 11 is an outlier, and the upper whisker stops at 7.5, the largest value inside the fence.

Because the quartiles split the data into four equal parts, each section of a boxplot holds about **25%** of the data: the lower whisker, the lower half of the box, the upper half of the box, and the upper whisker. A short section means those values are packed tightly; a long one means they are spread out. The sections are not equal in length, but they are equal in count.

**Skew shows in a boxplot too.** In a right-skewed distribution, the median sits closer to Q1 and the right whisker is longer. In a left-skewed distribution, the median sits closer to Q3 and the left whisker is longer. In the screen-time plot, the median is closer to Q1 and the upper whisker is longer, so the data are skewed right.

:::trap
**Common trap.** A longer section does not hold more data. Every quarter of the boxplot holds about the same number of values; length shows how spread out those values are.
:::

## Comparing groups with side-by-side boxplots

Boxplots shine when they sit side by side on one scale. Compare the groups on center (the medians), spread (the IQRs and ranges), shape, and outliers.

```figure
type: boxplot
caption: Test scores in two classes. Class B has the higher median and a much smaller IQR, so its scores are higher and more consistent.
axisLabel: Test score
groups:
  - { label: Class A, min: 50, q1: 62, median: 70, q3: 85, max: 98 }
  - { label: Class B, min: 58, q1: 72, median: 78, q3: 83, max: 90 }
```

- **Center**: Class B's median (78) is higher than Class A's (70).
- **Spread**: Class A's IQR is 85 - 62 = 23, while Class B's is 83 - 72 = 11. Class A's scores vary much more, and its range (48) is also larger than Class B's (32).
- **Quarters tell a story**: at least half of Class A scored 70 or lower, while at least three-quarters of Class B scored 72 or higher.

Write comparisons in context and with numbers: "Class B scored higher (median 78 versus 70) and more consistently (IQR 11 versus 23)."

::check{id="boxplots-03"}

## What a boxplot hides [Competitive]

A boxplot reduces a whole dataset to five numbers and a few dots, and that compression hides things.

- **Sample size.** A boxplot of 10 values and a boxplot of 10,000 values can look identical. The second is far more trustworthy, but nothing in the picture says so.
- **Peaks and gaps.** Two very different datasets can share the same five-number summary. Both datasets below have minimum 1, Q1 2.5, median 5, Q3 7.5, and maximum 9, so their boxplots are identical, yet the first is spread evenly and the second clumps into two groups.

```figure
type: dotplot
caption: Evenly spread values 1 through 9.
xLabel: Value
values: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

```figure
type: dotplot
caption: Values clumped at 2.5 and 7.5. The five-number summary, and so the boxplot, is the same as above.
xLabel: Value
values: [1, 2.5, 2.5, 2.5, 5, 7.5, 7.5, 7.5, 9]
```

- **The mean.** A standard boxplot shows the median, not the mean (some software adds a marker for the mean).

When the shape matters, pair the boxplot with a histogram, or use a violin plot (lesson 3.1), which shows the shape inside the box.

::check{id="boxplots-04"}

:::takeaways
- A histogram bins one numeric variable; bar height is the count (or percent) in each bin. Read shape, center, and spread.
- To find the median's bin, add counts from the left until you pass the middle position. A histogram hides the exact values inside each bin; estimate the mean with bin midpoints.
- Skewed right: tail on the right, mean above the median. Skewed left: tail on the left, mean below the median. Bimodal suggests two groups; uniform means roughly equal bars.
- Bin width changes the picture: wide bins hide peaks and gaps, and narrow bins exaggerate noise.
- A boxplot shows min, Q1, median, Q3, and max; the box is the IQR, and dots beyond 1.5 × IQR from the box are outliers.
- Each of the four sections of a boxplot holds about 25% of the data. A longer section means more spread, not more data.
- Compare boxplots on median, IQR and range, shape, and outliers, with numbers in context.
- A boxplot hides the sample size, the mean, and features such as two peaks or gaps.
:::
