Python is the most widely used language in data science, largely because of two libraries: NumPy for fast numerical arrays and pandas for tables. The objectives ask you to describe common packages such as pandas and NumPy and to discuss Python's use for cleaning and wrangling data. Test questions show a few lines of code and ask what they print, or ask which method does a job. Every output in this lesson comes from running the code with current versions of both libraries.

## Python lists versus NumPy arrays

**Python** is a general-purpose programming language known for readable code. Its built-in **list** holds any mix of values and can grow and shrink, but lists are not built for math. **NumPy** (Numerical Python) supplies the **array** (formally the `ndarray`), a grid of values that all share one data type, stored compactly so that math on whole arrays is fast. Travis Oliphant created NumPy in 2005 by unifying two earlier array packages.

The same symbols mean different things for lists and arrays:

```python run
import numpy as np

a = [1, 2, 3]
b = np.array([1, 2, 3])
print(a + a)
print(b + b)
print(a * 2)
print(b * 2)
```

```output
[1, 2, 3, 1, 2, 3]
[2 4 6]
[1, 2, 3, 1, 2, 3]
[2 4 6]
```

For lists, `+` **joins** them and `* 2` **repeats** the list. For arrays, both work **element by element**: each value is added to its partner or doubled. Notice also that NumPy prints arrays without commas.

An array has a single **dtype** (data type). Mixing whole numbers and decimals produces a float array: `np.array([1, 2.5, 3])` has dtype `float64`.

:::trap
**Common trap.** `[1, 2] + [3, 4]` is `[1, 2, 3, 4]`, not `[4, 6]`. Element-wise arithmetic needs NumPy arrays (or pandas columns).
:::

## Vectorization and broadcasting

**Vectorization** means applying an operation to a whole array at once instead of writing a Python loop over its elements. `prices * 2` doubles every price in one step. Vectorized code is shorter, and it is much faster, because the loop runs inside NumPy's compiled code rather than in Python.

**Broadcasting** lets NumPy combine arrays of different shapes by stretching the smaller one to fit. A single number (a scalar) is applied to every element, and a row can be added to every row of a table:

```python run
import numpy as np

prices = np.array([4.5, 3.0, 18.0])
print(prices * 2)

m = np.array([[1, 2, 3], [4, 5, 6]])
print(m + np.array([10, 20, 30]))
```

```output
[ 9.  6. 36.]
[[11 22 33]
 [14 25 36]]
```

The row `[10, 20, 30]` was added to each of the two rows. Broadcasting works when the shapes line up from the right, with each pair of dimensions either equal or 1: a 2-by-3 array combines with a length-3 row, but not with a length-2 array, which raises an error.

## Shape, axis, and boolean masks [Competitive]

Every array has a `.shape`, the size of each dimension. A table of 2 rows and 3 columns has shape `(2, 3)`.

Many functions take an **axis** argument. **axis=0** works down the rows and gives one result per column; **axis=1** works across the columns and gives one result per row.

A **boolean mask** is an array of True and False values made by a comparison. Indexing with it keeps only the positions that are True.

```python run
import numpy as np

scores = np.array([[88, 92, 75],
                   [95, 81, 89]])
print(scores.shape)
print(scores.sum(axis=0))
print(scores.sum(axis=1))
print(scores[scores > 90])
```

```output
(2, 3)
[183 173 164]
[255 265]
[92 95]
```

Summing with axis=0 added each column (88 + 95 = 183, and so on); axis=1 added each row (88 + 92 + 75 = 255). The mask `scores > 90` picked out 92 and 95.

One default matters for statistics questions. NumPy's `np.std` divides by n, giving the **population** standard deviation, unless you pass `ddof=1`. pandas does the opposite: its `.std()` divides by n - 1, the **sample** standard deviation (lesson 2.3).

```python run
import numpy as np
import pandas as pd

x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(np.std(x), np.std(x, ddof=1))
print(pd.Series(x).std())
```

```output
2.0 2.138089935299395
2.138089935299395
```

## pandas Series and DataFrames

**Pandas** (written in lowercase as pandas) is Python's main library for working with tables of data. Wes McKinney began building it in 2008, and its name comes from "panel data," an economics term for structured datasets. It is built on top of NumPy and adds labels, mixed column types, missing-value handling, and tools for reading, cleaning, and summarizing data.

pandas has two core structures:

- A **Series** is a one-dimensional labeled array: a column of values together with an **index** that labels each value.
- A **DataFrame** is a two-dimensional labeled table: rows labeled by an index and named columns. Each column of a DataFrame is a Series.

```python run
import pandas as pd

df = pd.DataFrame({
    "name": ["Ava", "Ben", "Chloe", "Dev"],
    "grade": [10, 11, 12, 10],
    "gpa": [3.6, 2.9, 3.9, 3.2],
})
print(df)
print(type(df["gpa"]).__name__, df.shape)
```

```output
    name  grade  gpa
0    Ava     10  3.6
1    Ben     11  2.9
2  Chloe     12  3.9
3    Dev     10  3.2
Series (4, 3)
```

The numbers 0 to 3 on the left are the default index. Selecting one column, `df["gpa"]`, returns a Series, and `df.shape` reports (rows, columns).

## Reading and inspecting data: read_csv, head, info, describe

Real data usually arrives as a file, and `pd.read_csv("file.csv")` loads a CSV into a DataFrame. (pandas also has `read_excel`, `read_json`, `read_sql`, and others.) Below, a small text buffer stands in for a CSV file so the example runs anywhere; note that Elena's GPA is blank.

```python run
import io
import pandas as pd

csv = io.StringIO("name,grade,gpa\nAva,10,3.6\nBen,11,2.9\nChloe,12,3.9\nDev,10,3.2\nElena,11,\n")
df = pd.read_csv(csv)
print(df.head(3))
df.info()
print(df.describe())
```

```output

dtypes: float64(1), int64(1), str(1)
```

Each inspection method answers a different first question:

- `df.head(n)` shows the first n rows (5 if you give no number); `df.tail(n)` shows the last n.
- `df.shape` gives (rows, columns). It is an attribute, so it takes no parentheses.
- `df.info()` lists every column with its count of non-null values and its dtype. Here it reveals the missing GPA: only 4 non-null values out of 5.
- `df.describe()` summarizes the numeric columns: count, mean, standard deviation (the sample version), minimum, quartiles, and maximum. Its count of 4 for gpa again shows the gap, and its mean skips the missing value.

:::tip
**Test tip.** "How many missing values are there?" points to `info()` (or `isna().sum()`, lesson 4.6). "What are the mean and quartiles?" points to `describe()`. "How many rows and columns?" points to `shape`.
:::

## Selecting data: columns, loc, iloc, boolean indexing

pandas offers several ways to pick out parts of a DataFrame:

- `df["gpa"]` selects one column as a Series; `df[["name", "gpa"]]`, with **double brackets**, selects several columns as a DataFrame.
- `df.loc[...]` selects by **label**. Its slices **include** the end label.
- `df.iloc[...]` selects by integer **position**. Its slices **exclude** the end position, like ordinary Python slices.

```python run
import io
import pandas as pd

csv = io.StringIO("name,grade,gpa\nAva,10,3.6\nBen,11,2.9\nChloe,12,3.9\nDev,10,3.2\nElena,11,\n")
df = pd.read_csv(csv)
print(df.loc[1:3, "name"])
print(df.iloc[1:3, 0])
```

```output
1      Ben
2    Chloe
3      Dev
Name: name, dtype: str
1      Ben
2    Chloe
Name: name, dtype: str
```

With the default index, the labels and positions are the same numbers, yet `loc[1:3]` returned three rows and `iloc[1:3]` returned two.

**Boolean indexing** filters rows with a condition. Combine conditions with `&` (and), `|` (or), and `~` (not), and wrap **each condition in parentheses**:

```python run
import io
import pandas as pd

csv = io.StringIO("name,grade,gpa\nAva,10,3.6\nBen,11,2.9\nChloe,12,3.9\nDev,10,3.2\nElena,11,\n")
df = pd.read_csv(csv)
print(df[(df["grade"] == 10) & (df["gpa"] > 3.5)])
```

```output
  name  grade  gpa
0  Ava     10  3.6
```

:::trap
**Common trap.** Python's `and` and `or` do not work on whole columns; `df[(df["gpa"] > 3) and (df["grade"] == 10)]` raises a ValueError. Use `&` and `|`, and keep the parentheses, because `&` binds more tightly than comparisons such as `==`.
:::

:::takeaways
- Python lists: + joins and * repeats. NumPy arrays: + and * work element by element. An array has one dtype.
- Vectorization applies an operation to a whole array at once, in fast compiled code. Broadcasting stretches a scalar or a compatible row to fit a larger array.
- shape gives each dimension, such as (2, 3). axis=0 gives one result per column; axis=1 gives one result per row. A boolean mask such as x[x > 3] keeps the True positions.
- np.std divides by n (population) by default; pandas .std() divides by n - 1 (sample).
- pandas (from "panel data") provides the Series, a labeled one-dimensional array, and the DataFrame, a labeled table whose columns are Series.
- read_csv loads a file; head shows the first rows; shape gives (rows, columns); info shows dtypes and non-null counts; describe summarizes numeric columns.
- df["col"] gives a Series; df[["a", "b"]] gives a DataFrame. loc selects by label and includes the end; iloc selects by position and excludes the end.
- Filter with & and |, each condition in parentheses; Python's and and or raise an error on columns.
:::
