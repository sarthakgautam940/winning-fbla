## Finding and handling missing values

pandas marks missing values as **NaN** ("not a number"), and it also treats Python's None as missing. A blank cell in a CSV file arrives as NaN. The first step in any cleaning job is to find the gaps, and `isna()` followed by `sum()` counts them column by column (`isnull()` is another name for the same method):

```python run
import pandas as pd

df = pd.DataFrame({
    "name": ["Ava", "Ben", "Chloe", "Dev"],
    "gpa": [3.6, None, 3.9, None],
    "club": ["Robotics", None, "Debate", "Robotics"],
})
print(df.isna().sum())
print(len(df.dropna()), len(df.dropna(subset=["club"])))
print(df["gpa"].fillna(df["gpa"].mean()).tolist())
```

```output
name    0
gpa     2
club    1
dtype: int64
2 3
[3.6, 3.75, 3.9, 3.75]
```

Three tools handle what you find:

- `isna()` marks each missing cell True; `.sum()` then counts them, because True counts as 1. (`notna()` is the opposite.)
- `dropna()` removes rows that contain any missing value: here only Ava and Chloe survive. `dropna(subset=["club"])` removes rows missing a club only, keeping 3 rows. `dropna(axis=1)` drops columns instead.
- `fillna(value)` replaces missing values. Filling with the column mean gave Ben and Dev a GPA of 3.75. For skewed data, fill with the median instead (lesson 3.5); for time series, `ffill()` carries the last value forward.

:::key
**Key idea.** pandas methods return a **new** object and leave the original unchanged. `df.dropna()` on its own line changes nothing; write `df = df.dropna()` to keep the result.
:::

## Duplicates and data types

`duplicated()` flags each row that repeats an earlier row, and `drop_duplicates()` removes them. Columns of numbers that arrived as text must be converted with `astype()` before you can do math on them:

```python run
import pandas as pd

df = pd.DataFrame({
    "order_id": [101, 102, 102, 103],
    "amount": ["12.50", "8.00", "8.00", "20.00"],
})
print(df.duplicated().tolist())
df = df.drop_duplicates()
df["amount"] = df["amount"].astype(float)
print(df["amount"].sum(), df.shape)
```

```output
[False, False, True, False]
40.5 (3, 2)
```

The third row repeats the second, so it is flagged and removed. Before the conversion, the amounts were text, and adding them would have joined strings rather than summing numbers.

Two variations come up often. `drop_duplicates(subset=["order_id"])` treats rows as duplicates when only those columns match, and `keep="last"` keeps the final copy instead of the first. When some values cannot convert, such as "N/A" in a number column, `pd.to_numeric(column, errors="coerce")` turns them into NaN instead of raising an error (lesson 1.7).

Checking types early saves trouble later. `df.dtypes` lists each column's type, and a column of numbers stored as text (shown as `str` or `object`) is a sign that something in it, such as a dollar sign or a stray word, needs cleaning first.

## apply, sort_values, and rename

When no built-in method fits, `apply` runs your own function on every value of a column (or on every row). A **lambda** is a short, unnamed function written inline: `lambda s: s * 2` takes a value s and returns twice that value. Two other everyday methods tidy the result: `rename` changes column names, and `sort_values` sorts the rows.

```python run
import pandas as pd

df = pd.DataFrame({"name": ["Ava", "Ben", "Chloe"], "score": [88, 72, 95]})
df["band"] = df["score"].apply(lambda s: "A" if s >= 90 else "B" if s >= 80 else "C")
df = df.rename(columns={"score": "points"}).sort_values("points", ascending=False)
print(df)
```

```output
    name  points band
2  Chloe      95    A
0    Ava      88    B
1    Ben      72    C
```

The lambda labeled each score with a band, the column `score` became `points`, and the rows were sorted from the highest score down. Notice that each row kept its original index label (2, 0, 1) when it moved; `reset_index(drop=True)` renumbers the rows from 0 if you need it.

`apply` is flexible but slow on large data, because it calls a Python function once per value. When a vectorized form exists, such as `df["score"] * 2` or a `.str` method, prefer it (lesson 4.5).

## Cleaning strings and dates [Competitive]

Text columns have a `.str` accessor that applies string methods to every value at once: `.str.strip()` removes surrounding spaces, `.str.lower()`, `.str.upper()`, and `.str.title()` change case, `.str.replace(old, new)` swaps text, and `.str.contains(pattern)` tests for a match. Chaining them standardizes messy categories:

```python run
import pandas as pd

city = pd.Series([" Austin", "denver", "DENVER ", "Boston"])
print(city.str.strip().str.title().value_counts())

dates = pd.to_datetime(pd.Series(["2025-06-01", "2025-06-15"]))
print(dates.dt.day_name().tolist(), (dates[1] - dates[0]).days)
```

```output
Denver    2
Austin    1
Boston    1
Name: count, dtype: int64
['Sunday', 'Sunday'] 14
```

Before cleaning, "denver" and "DENVER " counted as different cities; afterward they merge into Denver with a count of 2.

`pd.to_datetime()` converts text into real dates. Real dates sort in time order, support subtraction (June 15 minus June 1 is 14 days), and offer a `.dt` accessor for parts such as `.dt.year`, `.dt.month`, and `.dt.day_name()`. Text dates sort alphabetically, so "10/2/2025" would come before "9/30/2025"; converting first avoids that.

Real cleaning jobs chain several of these steps together.

::::example[Cleaning a price column]
A price column arrived as text: "$1,200", "N/A", " 950 ", and "$1,050". Turn it into numbers and fill the gap.

:::step
Strip the spaces and remove the symbols with `price.str.strip().str.replace("$", "").str.replace(",", "")`, which gives "1200", "N/A", "950", and "1050".
:::

:::step
Convert with `pd.to_numeric(..., errors="coerce")`. The text "N/A" cannot become a number, so it turns into NaN: 1200.0, NaN, 950.0, 1050.0.
:::

:::step
Fill the gap with the median of the known prices, 1,050, which extreme prices cannot pull around: `clean.fillna(clean.median())`.
:::

:::answer
The cleaned column is 1200.0, 1050.0, 950.0, 1050.0.
:::
::::

```python run
import pandas as pd

price = pd.Series(["$1,200", "N/A", " 950 ", "$1,050"])
clean = pd.to_numeric(price.str.strip().str.replace("$", "").str.replace(",", ""), errors="coerce")
print(clean.tolist())
print(clean.fillna(clean.median()).tolist())
```

```output
[1200.0, nan, 950.0, 1050.0]
[1200.0, 1050.0, 950.0, 1050.0]
```

## groupby and agg

`groupby` is pandas' version of SQL's GROUP BY (lesson 4.3). It follows a pattern called **split-apply-combine**: split the rows into groups by a column's values, apply a calculation to each group, and combine the results into one table. `value_counts()` is the quick way to count each category.

```python run
import pandas as pd

sales = pd.DataFrame({
    "region": ["East", "West", "East", "West", "East"],
    "units": [10, 4, 6, 8, 2],
})
print(sales.groupby("region")["units"].sum())
print(sales.groupby("region")["units"].agg(["count", "mean"]))
print(sales["region"].value_counts())
```

```output
region
East    18
West    12
Name: units, dtype: int64
        count  mean
region
East        3   6.0
West        2   6.0
region
East    3
West    2
Name: count, dtype: int64
```

Grouping one column with one function returns a Series whose index holds the group labels (East, West). `agg` applies several functions at once and returns a DataFrame with one column per function. `value_counts()` sorts from the most common value to the least, so the top category always comes first.

## merge, join, and concat

`merge` combines two DataFrames on a shared column, exactly like a SQL join, and its `how` argument names the join type: `"inner"`, `"left"`, `"right"`, or `"outer"`.

```python run
import pandas as pd

students = pd.DataFrame({"student_id": [1, 2, 3], "name": ["Ava", "Ben", "Chloe"]})
scores = pd.DataFrame({"student_id": [1, 1, 3, 4], "score": [88, 92, 95, 70]})
print(students.merge(scores, on="student_id", how="left"))
print(len(students.merge(scores, on="student_id", how="inner")),
      len(students.merge(scores, on="student_id", how="outer")))
```

```output
   student_id   name  score
0           1    Ava   88.0
1           1    Ava   92.0
2           2    Ben    NaN
3           3  Chloe   95.0
3 5
```

The row-count rules from SQL carry over (lesson 4.4). The left merge keeps every student, so Ben appears with NaN, and Ava appears twice because Ava has two scores: 4 rows. The inner merge keeps only matches (3 rows), and the outer merge adds the score for student 4, who has no name (5 rows). The score column became decimals because NaN is a float value.

When the key columns have different names in the two tables, use `left_on="id"` and `right_on="student_id"` instead of `on`. If both tables have a non-key column with the same name, pandas keeps both and adds suffixes such as `_x` and `_y` to tell them apart.

`df.join(other)` is a shortcut that merges on the index instead of a column. `pd.concat` **stacks** DataFrames: by default it adds rows (`axis=0`), and with `axis=1` it places them side by side:

```python run
import pandas as pd

d = pd.DataFrame({"a": [1, 1, 2], "b": [5, 5, 5]})
print(pd.concat([d, d]).shape, pd.concat([d, d], axis=1).shape)
```

```output
(6, 2) (3, 4)
```

## pivot_table and melt [Competitive]

Data comes in two shapes. A **long** table has one row per measurement; a **wide** table spreads the measurements across columns. `pivot_table` turns long data into wide data and aggregates along the way; `melt` turns wide data back into long data, which is the tidy form (lesson 1.7):

```python run
import pandas as pd

sales = pd.DataFrame({
    "region": ["East", "East", "West", "West"],
    "quarter": ["Q1", "Q2", "Q1", "Q2"],
    "units": [10, 6, 4, 8],
})
wide = sales.pivot_table(index="region", columns="quarter", values="units", aggfunc="sum")
print(wide)
print(wide.reset_index().melt(id_vars="region", value_name="units"))
```

```output
quarter  Q1  Q2
region
East     10   6
West      4   8
  region quarter  units
0   East      Q1     10
1   West      Q1      4
2   East      Q2      6
3   West      Q2      8
```

In `pivot_table`, `index` sets the rows, `columns` sets the new columns, `values` chooses what fills the cells, and `aggfunc` decides how repeated combinations are combined (the mean, by default). In `melt`, `id_vars` names the columns to keep as identifiers, and the other columns are unpivoted into variable and value pairs.

:::tip
**Test tip.** Match the verb to the shape change. Long to wide, with a summary in each cell: `pivot_table`. Wide to long: `melt`. Same columns, more rows: `concat`. Matching rows on a key: `merge`.
:::

:::takeaways
- isna().sum() counts missing values per column; dropna() removes rows with missing values (subset= limits the check); fillna() fills them; ffill() carries values forward.
- Methods return new objects: write df = df.dropna() to keep the change.
- duplicated() flags repeats and drop_duplicates() removes them (subset= and keep= adjust it). astype() converts types; pd.to_numeric(..., errors="coerce") turns bad values into NaN.
- apply runs a function, often a lambda, on every value; rename changes column names; sort_values sorts rows. Prefer vectorized operations to apply when they exist.
- The .str accessor cleans text (strip, lower, title, replace, contains); pd.to_datetime makes real dates with a .dt accessor.
- groupby splits, applies, and combines; agg applies several functions; value_counts counts categories, most common first.
- merge mirrors SQL joins with how="inner", "left", "right", or "outer"; join merges on the index; concat stacks rows (axis=0) or columns (axis=1).
- pivot_table turns long data wide with aggregation; melt turns wide data long.
:::
